Without that guard the button renders on a machine with no credentials, sends the user to Google, and returns an error page; hiding it means development and CI show the username form alone rather than a control that cannot work. It is a POST form, not a link. allauth accepts GET for provider login, but starting a login from a GET means any page that can make the browser fetch a URL can start it; the POST plus CSRF token keeps the flow something the user actually asked for.
