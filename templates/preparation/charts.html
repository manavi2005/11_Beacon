Matplotlib, rendered server-side and served as PNG

Every chart below is drawn at request time from the database. The ORM does the aggregation, Matplotlib draws the figure into an in-memory buffer, and the view returns it as image/png. No image file is written to disk, and nothing is precomputed. Each chart also has its own URL, so it can be opened on its own or linked to directly.
